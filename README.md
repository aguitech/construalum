# ConstruAlum®

> *"Soluciones fuertes, estructuras fuertes"*

Sitio web oficial de **ConstruAlum — Estructuras en vidrio y aluminio** en Morelia, Michoacán.

## 🏗️ Acerca de ConstruAlum

Suministro e instalación de estructuras modernas e inteligentes en vidrio y aluminio, cancelería de PVC, vidrio templado, herrería de alto nivel, barandales, domos, techumbres y más.

**Fundada en 2015** · **+800 proyectos completados** · **10 servicios especializados**

## 🚀 Stack

- HTML5 semántico
- CSS3 vanilla con paleta azul corporativo + acentos cristal
- JavaScript vanilla puro, **cero dependencias**
- 100% responsive
- Optimizado para SEO local (Morelia, Michoacán)
