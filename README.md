# ConstruAlum®

Sitio web oficial de ConstruAlum — Estructuras en vidrio y aluminio.

> *"Soluciones fuertes, estructuras fuertes"*

## 🚀 Stack

- HTML5 semántico
- CSS3 vanilla con paleta azul corporativo + acentos cristal
- JavaScript vanilla puro, **cero dependencias**
- 100% responsive

## 📂 Estructura

```
construalum/
├── index.html              # Landing
├── nosotros.html           # Empresa, pilares, especialidades
├── servicios.html          # Catálogo completo (10 servicios)
├── galeria.html            # Galería con lightbox
├── contacto.html           # Form + info
├── servicios/
│   ├── anti-estornudos.html
│   ├── aplicaciones-vidrio.html
│   ├── barandales.html

│   ├── repisas.html
│   └── techumbres.html

    ├── logo.svg
    └── servicios/
```
